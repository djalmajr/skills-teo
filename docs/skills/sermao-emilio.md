# sermao-emilio

Agent source of truth: [`skills/sermao-emilio/SKILL.md`](../../skills/sermao-emilio/SKILL.md)

## When to use

- Preparar sermão, esboço ou manuscrito oral
- Reescrever mensagem fria em tom pastoral-narrativo
- Estruturar texto bíblico com história do cotidiano e costuras no meio

## When not to use

- Estudo exegético técnico sem intenção de pregação
- Artigo acadêmico
- Devocional de um parágrafo (a menos que o usuário peça explicitamente)

## Assets

- `examples/` — fichas curtas de estrutura
- `transcriptions/` — prosa longa para calibrar voz e ritmo

## Output

Artefato com metadados (texto, ocasião, tese, história-porta), esboço rápido, manuscrito oral e notas de pregação.
