# Curadoria

Não é um quarto debatedor. Não escolhe escola. Confere se as **referências batem** e se o **debate** cumpriu o protocolo.

Quem mediou não é o único olho nesta ficha. Prefira um subagente isolado (mesmo `kind`, sem o histórico de quem julgou os turnos).

**Veredito:** PASS / PASS com WARN / RETRY

Esta ficha **não** publica livro. Volume é a skill `teo-livro`.

## 1. Referências

Para cada citação de **carga** (a que sustenta um eixo da agenda ou uma mestra) e para uma amostra das de apoio:

| Ref. | Onde (peça) | A frase afirma | O texto diz isso? | Nota |
|---|---|---|---|---|
| | | | sim / leitura da escola / não | |

- **sim** — o versículo contém o que a frase atribui (citação ou paráfrase honesta).
- **leitura da escola** — o versículo existe e é aquele; o *alcance* é a briga (não é erro de fonte).
- **não** — versículo errado, citação inventada, ou a frase diz o que o texto não diz.

`não` numa citação de carga → RETRY da peça se o turno ainda admite retrabalho; senão, anote no veredito. Não reclassifique isso como “interpretação”.

Alusão sem livro-capítulo-versículo → WARN, e complete a fonte na peça se ainda for possível.

## 2. Debate

Leia `qualidade.md` e `veredito.md` §1. Confirme:

- [ ] Verificação de turno existiu *antes* da síntese, não só no fim
- [ ] Mal-entendido corrigido no ciclo, não só na declaração final
- [ ] Os três discordam da pergunta real; ninguém saiu da escola
- [ ] `indice.md` aponta o debate (síntese, veredito, turnos), não um volume
- [ ] Não se compilou `livro/` nesta pasta
