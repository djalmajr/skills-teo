# Entrevista inicial

Rode **antes** de criar a pasta e **antes** de rascunhar. O livro nasce destas respostas.

Use a ferramenta de pergunta estruturada (`ask_user_question` / `AskUserQuestion` / `question`). Um cartão. Segunda rodada só se a resposta for fina.

## Cartão 1

1. **Qual é o tema deste livro?**
   - Uma frase. Não um caminho.

2. **Qual é o insumo?**
   - Um debate já fechado (pasta `Debate - …/`).
   - Notas / artigo já escritos (o usuário nomeia).
   - Tópico nu: a pesquisa é o primeiro trabalho.
   - `Outro` = descrever.

3. **Quem lê?**
   - Crente inteligente, sem diploma (recomendado).
   - Leitor técnico / seminário.
   - `Outro`.

4. **O que o volume constrói?** (fio + destino)
   - O fio em ≤20 palavras e o que o leitor deve conseguir *depois*.
   - `Outro` = as duas frases.

5. **Qual estrutura?**
   - `quatro-pontos` (recomendado se o insumo for debate).
   - `inquerito`.
   - `voz-unica`.
   - `Outro` = descrever. Confirme contra `estruturas.md`.

6. **Idioma?**
   - Português do Brasil (recomendado).
   - `Outro`.

7. **Onde vive o volume?**
   - `Livro - <tema>/` no diretório atual (recomendado). **Não** dentro da pasta do debate.
   - `Outro` = nome da pasta.

8. **Próximo passo?**
   - Só montar orientação + plano de capítulos; eu confirmo o fio.
   - Pesquisar, fazer o plano de capítulos e escrever (piloto, depois o resto).
   - Ainda não.

## O que a entrevista inicial grava

`raw/00-brief.md`: tema, insumo (caminhos **relativos** se for debate/notas), leitor, fio, destino, estrutura, idioma.

Não rascunhe capítulos enquanto a pergunta 8 não autorizar a escrita.

Se o insumo for debate, o dossiê do debate **não se move**. Esta pasta é outra.
