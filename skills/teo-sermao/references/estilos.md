# Catálogo de estilos

Um id = um arquivo `estilos/<id>.md`. Aliases só aqui.

| id | Aliases | Uma linha |
|---|---|---|
| `emilio` | emílio, garofalo, garófalo, narrativo, narrativo-pastoral, história-porta, `/teo-sermao-emilio` | Cena do cotidiano abre, volta no meio, graça no fecho |
| `expositivo` | exposição, textual, verse-by-verse, sem história-porta | Segue o movimento do texto; tese cedo; aplicação em cada parte |

Padrão da skill: `emilio`. Opção: `--estilo=<id>`.
