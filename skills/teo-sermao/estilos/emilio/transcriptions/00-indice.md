# Transcrições formatadas — pregações-base do estilo Emílio

Textos reescritos a partir das **legendas automáticas** dos quatro vídeos usados para modelar a skill. Formato de **artigo legível** (prosa editorial com seções, sem marcações de tempo):

- sem marcações de tempo
- pontuação e parágrafos revisados
- erros óbvios de legenda automática corrigidos
- vícios de oralidade suavizados (sem apagar o tom pastoral)
- sentido da exposição preservado

Use estas transcrições para calibrar **voz, ritmo, densidade de exemplos do cotidiano e costura com o texto** — não para copiar sermões prontos.

## Relação com `examples/`

- `examples/` = fichas curtas de **estrutura** (história-porta, costuras, tese, arco)
- `transcriptions/` = **prosa completa formatada** dos mesmos quatro vídeos

Ao criar sermão novo:

1. use `examples/` para montar a ossatura
2. leia 1 trecho de `transcriptions/` (abertura + uma seção do meio) para calibrar a voz
3. produza conteúdo original para o texto pedido

## Formato padrão de cada arquivo

```markdown
# Título do sermão/artigo

*Contexto — Rev. Emílio Garofalo*

[corpo em seções com ##]

---

*Baseado na exposição de Rev. Emílio Garofalo.*
```

## Nota

Estas são reescritas editoriais a partir de ASR/legendas do YouTube. Podem restar imprecisões pontuais de nomes ou detalhes; o objetivo é voz e forma legível para calibração da skill, não publicação acadêmica crítica.
